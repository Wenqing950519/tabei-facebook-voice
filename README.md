# TABEI Facebook 粉專寫作 skill

把訪談、演講、論壇與媒體問答的逐字稿轉成臺灣區塊鏈愛好者協會（TABEI）Facebook 的會後談和議題解說。依素材選擇敘事方式，也可以為同一份逐字稿寫不同角度的版本。

## 匯入內容管理器

- 若內容管理器支援 GitHub skill 匯入，使用本公開 repository 的 URL，入口為根目錄的 [SKILL.md](SKILL.md)。
- 若支援檔案或資料夾匯入，請下載整個 repository，保留 `SKILL.md`、`references/` 和 `agents/` 的相對路徑。`references/` 內含寫法選擇與九月會後文樣本說明。
- 匯入後可用一段逐字稿試跑，例如「把這份逐字稿寫成一篇協會粉專會後談，選一種適合的寫法。」檢查講者姓名與職稱、觀點歸屬與正文格式。

本專案提供 skill 檔案。匯入方式與適用檔案格式以內容管理器實作為準。
