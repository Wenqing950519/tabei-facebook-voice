# 依素材選寫法

下列是可選的敘事方法。依照哪一段材料最能說清讀者的問題來挑選，段數、標題和起落都可以變動。九月貼文對照見 [九月會後文樣本](september-voice.md)。

| 寫法 | 什麼素材適合 | 正文怎麼推進 |
| --- | --- | --- |
| 跟著一個案例走 | 有清楚的生活情境、金融流程，或可用假設說明一個具體卡點 | 把讀者帶到事情卡住的那一步，解釋中間有哪些人、資料或權限，再回看講者的看法。例子要能解釋機制。 |
| 拆一個講者主張 | 一句話就能指認講者的主張，而且有理由或例子可展開 | 先讓讀者知道這個主張要回答什麼，再解釋它成立的理由與適用場景。可以從主張或現場脈絡開頭，收在實務上的判斷。 |
| 用兩個視角看同一題 | 兩位講者或兩種角色對同一問題各自提供可核對的內容 | 先立好共同問題，再交代各自看到什麼、兩個視角怎麼接起來。若有分歧，寫出分歧的實際內容。素材只有一方清楚時，以那一方為主。 |
| 從會後觀察切入 | 不只一場發言，且有具體活動片段或場次共同指向一項變化 | 用現場看到的事交代脈絡，選有關聯的片段支持協會觀察，再說這對產業有什麼影響。從觀點延伸時，讓讀者看得出是哪一方的判斷。 |
| 把一題問答講透 | 媒體或觀眾問到一個明確疑問，答覆有辨識度 | 用問答中最值得帶走的答案破題，補交代原問題和必要的定義或角色。保留講者實際回答的界線。適合寫得短，不必回顧整場。 |
| 追一項合作的實際進度 | 有公告、規劃或採用進展，素材也交代已做到哪裡、再來要解決什麼 | 從有證據的進度或卡點講起，說清楚各方要準備什麼，以及什麼進展可以再觀察。用明確措辭區分已完成、規劃中和講者期待。 |

如果一場座談有幾個彼此獨立、又能回答同一主題的面向，可以用少量「▍」小標逐段展開。只有一段內容特別扎實時，讓它單獨成篇。像 9/25 和 9/26 的 ETHTaipei 貼文，同一場演講可按兩個讀者問題拆成兩篇。

開頭可獨立換成案例中的動作、講者的主張、現場一個具體發現或與讀者有關的問句。收尾可停在流程中最關鍵的一步、講者說法帶給產業的判斷、尚待觀察的下一件事。前後應回答同一條主線。別因為起手式變了，就以為是另一版。
